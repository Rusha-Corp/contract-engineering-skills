# CENG-T013-P005-EV001

Implemented structured gate-failure diagnostics and adapter conformance in
`scripts/gate_diagnostics.py`, with thin adapter modules in
`adapters/factory-droid/diagnostics.py`, `adapters/generic/diagnostics.py`,
and `adapters/hermes/diagnostics.py`.

The diagnostic envelope has seven stable machine-readable codes:
- GATE-SCOPE-001 (scope violation, blocking)
- GATE-EVIDENCE-001 (missing evidence, blocking)
- GATE-STATE-001 (illegal state transition, blocking)
- GATE-SECURITY-001 (security finding, always blocking)
- GATE-SECURITY-002 (missing security capability, always blocking)
- GATE-DEPENDENCY-001 (missing dependency, warning)
- GATE-HASH-001 (hash mismatch, blocking)

Every diagnostic includes actionable remediation text. Security codes are
fail-closed: `emit_diagnostic` forces `blocking=True` even when callers
request `blocking=False`. The `conform_adapter` function validates that all
required envelope fields are present before returning.

Three output formats are supported: JSON (machine-readable), human (terminal),
and markdown (documentation).
