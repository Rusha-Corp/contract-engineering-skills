# CENG-T013-P005-EV001

Implemented the shared diagnostic envelope in `scripts/gate_diagnostics.py`
and explicit adapter modules for Factory Droid, Generic, and Hermes.
Diagnostics use stable `GATE-*` codes, actionable remediation, and common
fields. Security diagnostics force `severity: error` and `blocking: true`,
even when callers request a downgrade.

Validation:

- `python3 -m unittest tests.test_gate_diagnostics -v`: passed, 5 tests.
- `python3 -m unittest discover -s tests -p 'test_*.py'`: failed with one
  pre-existing unrelated error: `CENG-T004-P017 state mismatch ('Handoff' !=
  'Rework')` in `test_validates_repository_tracker_partitions`.

The full-suite limitation is outside P005 scope. No remote systems or
external effects were used.
