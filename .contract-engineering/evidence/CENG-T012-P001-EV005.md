# CENG-T012-P001-EV005

## Result

Remote CI accepted the signed `v2.5.3` attestation and tag, but the records
job failed in the repository unit tests. YAML parses unquoted ISO dates as
native `date` values, while the tracker validator accepted only strings.

## Correction

- Do not rewrite the existing remote `v2.5.3` tag.
- Preserve the failed run and mark `v2.5.3` unverified.
- Accept YAML-native `date` values while retaining ISO-string validation.
- Publish the correction as `v2.5.4`.

## Validation

The failed CI run is retained as release-gate evidence. The corrective release
must pass the full Python 3.12 workflow and signed-tag stable gate before it
is treated as verified.
