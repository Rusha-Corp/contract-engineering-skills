## Fix 2 — validator rejects unresolvable handoff revisions (commit 0f9401a)

- RED: test_fabricated_full_length_revision_fails failed with
  "ValueError not raised".
- Discovery during GREEN: git rev-parse --verify --quiet accepts any
  well-formed 40-hex string without an existence check (git 2.39.3),
  which is how fabricated SHAs survived every prior check. The check uses
  git cat-file -e instead.
- GREEN: 4/4 tests in tests.test_contract_records.HandoffRevisionTests;
  the check is skipped outside a Git work tree and exempts legacy
  'worktree' placeholders and short SHAs.
- The new check immediately caught 17 unresolvable 40-hex revisions in 14
  legacy handoffs (CENG-T004-P021/P023, T007-P003, T010-P001, T011-P002
  .. P006, T015-P002 .. P007) whose objects were destroyed by early-era
  history rewrites. Repaired in the same commit: unresolvable
  head_revisions repointed at each handoff's surviving records commit
  (git log -1 -- <handoff>), unresolvable base_revisions blanked (intent
  unverifiable).
