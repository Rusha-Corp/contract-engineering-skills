  alias-count checks before object construction.

  cannot echo submitted content.

  the CI workflow timeout and read-only isolation as additional bounds.
- Added five focused unit tests covering valid YAML and rejection of oversized,
  deeply nested, alias-heavy, malformed, and secret-bearing input.
- Validation passed: all five unit tests, bounded contract validation, Python
  compilation, and whitespace checks.

  configured address-space limit.
